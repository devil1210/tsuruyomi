# Deployment Configurations (`deploy`)

## Overview
The `deploy` directory organizes deployment specifications, orchestration manifests, and infrastructure automation configurations for running Tsuruyomi in production environments.

## Subdirectories & Boundaries
- [ProxMenux Proxmox OCI Deployment](./proxmenux/README.md): Official ProxMenux OCI container templates, multi-LXC stack topologies, and catalog synchronization tools for Proxmox VE.
